# Academic Excellence Olympiad (AEO) Portal

Ye software ka pura bundle hai, jisko aap seedhe Github aur Vercel par host kar sakte hain.

## Kaise Deploy Karein?
1. Is ZIP ko extract karein.
2. Naye folder me command line kholein aur type karein: `npm install`
3. Check karne ke liye `npm run dev` type karein.
4. Pura folder GitHub me naye repository me daal dein (Drag and drop ya Git push).
5. Vercel par us GitHub repo ko import karein. Vercel automatically React app ko deploy kar dega!
